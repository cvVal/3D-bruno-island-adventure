# 3D Bruno Island Adventure

## About the Game

**3D Bruno Island Adventure** is an action-adventure game featuring Bruno, a brave adventurer exploring a mysterious island.

Experience a blend of exploration, combat, dialogue, and questing in this 3D adventure!

## Gameplay Controls

### Keyboard & Mouse

| Action       | Key               |
|--------------|-------------------|
| **Movement** | WASD              |
| **Interact** | F / return        |
| **Attack**   | Left Mouse Button |
| **Block**    | E                 |
| **Heal**     | Q                 |
| **Dash**     | Shift             |
| **Pause**    | ESC               |

### Gamepad Controls

| Action                | Button             |
|-----------------------|--------------------|
| **Movement**          | Left Stick         |
| **Interact / Select** | A / East           |
| **Attack**            | Y / West           | 
| **Block**             | ZR / Right Trigger |
| **Heal**              | X / North          | 
| **Dash**              | R / Right Shoulder | 
| **Pause / Back**      | Start / Plus       |
